# Reader

تطبيق مذاكرة بسيط: **PDF + Word + Excel + PowerPoint** (عرض وتعديل وإنشاء) — ويب PWA + APK أندرويد.

## المميزات
- 🗂 الشاشة الرئيسية فيها 4 تبويبات: **PDF** (وفيه الملاحظات ودمج الملفات) / **PowerPoint** / **Word** / **Excel**، وكل تبويب له ملفاته وأزراره.
- 📄 PDF: قلم وهايلايتر وممحاة ونص وصور، تحديد النص وتظليله، بحث، علامات، صفحات، تصدير PDF بالكتابة عليه، دمج ملفات.
- 📑 Word / Excel / PowerPoint: فتح وتعديل وحفظ كنسخة جديدة (الأصل ما بيتلمسش).
- 🧩 PowerPoint: زرار «🧩 مخططات جاهزة» في تبويب الإدراج — هيكل تنظيمي، شجرة هرمية، هرم، عمليات (أفقية/رأسية/دورة)، علاقات (محوري/فن/مصفوفة)، خط زمني، وكمان مكتبة أشكال المخططات الانسيابية والموصلات. كل عنصر بيتعدّل ويتحرّك لوحده.
- ✏️ PowerPoint (تعديل): زرار «✏️ تعديل» — تنسيق النص (غامق/مائل/خط/حجم/لون/محاذاة)، إضافة/حذف/تكرار/ترتيب الشرايح، صور وأشكال وجداول، وعرض شرايح بانتقالات (تلاشي/انزلاق/تكبير) وبيتحفظ كنسخة جديدة. كمان: تراجع/إعادة، نسخ/لصق، خطوط، قوائم وترقيم، تباعد أسطر، تدوير، ترتيب الطبقات، محاذاة، حدود وظل، صفوف/أعمدة/دمج خلايا الجدول، واستبدال نص في كل الشرايح. الكود في `pptedit.js`.
- 🎬 PowerPoint: تشغيل الصوت والفيديو اللي جوه الشرايح (زرار على كل ملف + قائمة «🎬 الوسائط» بكل الملفات). الصوت غير المدعوم (wma / aif / amr) بيتحوّل mp3 بزرار «🔄 حوّل الصوت لـ mp3» ويتحفظ PPTX جديد (بيستخدم ffmpeg.wasm، حوالي 30MB زيادة في الـAPK).
- 🌐 ترجمة: حدد أي نص في الـPDF واضغط «ترجمة» (عربي ⇄ إنجليزي، محتاجة نت).
- 📝 ملاحظات بخلفيات (أبيض / سطور / مربعات / نقاط).
- 🔒 قفل أي ملف بالرقم السري، 🌙 وضع ليلي، ⏱ مؤقت مذاكرة 25 دقيقة، 💾 نسخة احتياطية واسترجاع.
- كل ملفاتك على جهازك بس، ومفيش أي خدمة خارجية (غير الترجمة: النص المحدد بس بيتبعت لخدمة ترجمة جوجل/MyMemory).

## الملفات

## التشغيل على الويب
افتح `index.html` من أي سيرفر ثابت (مثلًا `npx serve .`). أول مرة محتاجة نت، وبعدها بيشتغل أوفلاين. لو عايز تفرض تحديث الكاش غيّر `V` في `sw.js`.

## بناء APK
الـworkflow في `.github/workflows/build.yml` بيبني الـAPK مع كل push على `main` وينشره في Releases (tag: `latest`).

عشان كل نسخة تتثبّت فوق اللي قبلها:
1. اعمل مفتاح مرة واحدة: `keytool -genkey -v -keystore debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"`
2. حوّله: `base64 -w0 debug.keystore` وحطه في GitHub → Settings → Secrets → اسمه `DEBUG_KEYSTORE_B64`.
3. شغّل `npm install` مرة محليًا وارفع `package-lock.json` عشان إصدارات المكتبات تثبت.

## ملاحظات
