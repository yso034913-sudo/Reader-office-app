# Reader All — Android source (v4.2.0)

Reader All is a mobile-first Office document reader and editor with PDF conversion. The Android project is generated by Capacitor during the build; this ZIP contains the source bundle, not a prebuilt APK.

## Build the APK

```bash
npm install
bash scripts/build.sh
```

The output is `Reader All.apk` in the project root.

## Android application identity

- Android application ID / Capacitor appId: `com.readerall.app`. This is a new app identity; Android installs it as a separate app, independent of any other app you have installed.
- Keep this ID unchanged for future releases. Changing it again creates another separate app.

## Android integration

- Incoming `.docx`, `.xlsx`, `.xls`, `.csv`, and `.pptx` files are registered for Android **Open with** and **Share to** actions. The native activity reads the shared content URI and passes the file into the existing Office import flow.
- Camera permission is requested only when the user starts document scanning. Microphone permission is requested when the user taps **🎙 تسجيل صوت للسلايد** in the PowerPoint editor. Each recording is embedded as an audio object on the currently selected slide and saved with the exported `.pptx` file.
- `scripts/patch-android.py` applies the Android intent filters and installs the incoming-file activity after Capacitor creates/synchronizes the Android project.
- Files are imported into the app's local document store. The original file shared from another app is not modified.

The APK must be rebuilt and installed for these Android changes to take effect. The source changes have been syntax-checked; a full Android APK build/device test was not available in this environment. PDF viewing, annotation, search, and merging are not included. Exporting supported Office documents to PDF remains available.

- Audio embedded in PowerPoint (except MIDI, which is a note-event format rather than encoded audio) is converted to MP3 automatically in the background. Converted audio is cached in the app's document store and reused when the same presentation is reopened; the original embedded media is preserved.
- WMA files can be inserted into PowerPoint slides. Playback uses the background MP3 cache when conversion succeeds; if the device cannot decode WMA and conversion is unavailable, the player attempts an in-memory fallback without modifying the original.
- Full `.rabak` backups (older `.inkbak` backups can still be restored) include Word, Excel, PowerPoint and note records, their primary binary data, attached/cached media and Reader All local preferences. Restore remains compatible with older notes-only backup files. PDF records are intentionally excluded because PDF viewing is not part of this app.

## Stable signing key (so every build installs over the previous one)

The workflow builds a **debug** APK. Without a fixed key each build is signed differently and Android refuses to update the installed app (you must uninstall first). To keep one key:

```bash
keytool -genkey -v -keystore debug.keystore -storepass android -alias androiddebugkey \
  -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
base64 -w0 debug.keystore   # macOS: base64 -i debug.keystore
```

Save the output as a GitHub repository secret named `DEBUG_KEYSTORE_B64` (Settings → Secrets and variables → Actions). Keep `debug.keystore` safe and never commit it (it is in `.gitignore`).

## Dependencies

Run `npm install` once and commit the generated `package-lock.json`; the workflow then uses `npm ci` for reproducible builds. Excel support uses SheetJS 0.20.3 from the official tarball (the npm registry copy 0.18.5 has known vulnerabilities).


## Internal names

All internal identifiers use the Reader All name: IndexedDB `readerall`, localStorage keys `ra*`, JS globals `ra*`, backup extension `.rabak`, encrypted-file extension `.raenc`. On first launch after upgrading, data from the old `inkpad` database and old `ink*` preference keys is copied over automatically; old `.inkbak` / `.inkenc` files can still be opened.

## Word editor (v4.3 — wordpro.js)

- **Tables**: insert dialog (rows, columns, header row, borders, width, direction) and a ⚙ panel: add/delete rows and columns, merge/split cells, header row that repeats on every page, borders (all/none/outer/inner/horizontal/vertical, colour, thickness), cell alignment and shading, column widths, table width/alignment/direction, zebra rows, delete table. Borders, widths, merges and vertical alignment are exported to .docx.
- **Images**: tap an image to resize (%, cm), align, or delete; large photos are down-scaled and converted to PNG/JPEG on insert; paste from clipboard works. Size is exported relative to the page content width.
- **Arabic / direction**: 🌐 panel sets RTL / LTR / auto for the whole document, the current paragraph(s) or a table. Exported as bidi paragraphs. Existing RTL documents are detected on open.
- **Page setup**: 📄 dialog — A4/A5/Letter/Legal, portrait/landscape, margins (presets or custom, cm), header/footer distance.
- **Header / footer**: typed directly at the top/bottom of the page (alignment, hide on first page). Read back from existing .docx files so they are no longer lost when editing.
- **Page numbers**: header or footer, alignment, formats (1 / صفحة 1 / صفحة 1 من N / - 1 -), digits (1 2 3 / ١ ٢ ٣ / roman), start number, hide on first page.
- **Page breaks**: ⎘ inserts a visible break; ↧ starts the current paragraph on a new page. Page guides in the editor are approximate.
- Not covered: this source was only syntax-checked (no device or Word test).

## Word page view (real Office layout)

- The sheet is drawn at the real paper size (A4 = 21 × 29.7 cm, 1 inch margins, header/footer distances) and scaled to fit the screen width, instead of reflowing into a narrow phone column.
- Default typography matches Word: Calibri 11 pt, line spacing 1.08, 8 pt after each paragraph. New .docx exports use the same defaults (11 pt, 1.08, 8 pt after).
- Zoom: pinch with two fingers, or use the − / + pill at the bottom-left (tap the % to fit to the screen). Print / PDF export ignore the screen zoom.
- Calibri is not bundled on Android; the browser substitutes a similar font, so line breaks can differ slightly from Word on a PC.

## Fonts

- The Word font list now really changes the text on Android. Latin fonts are bundled in `fonts/` (subset, ~430 KB) and registered under the Office names: Calibri→Carlito, Cambria→Caladea, Arial→Liberation Sans, Times New Roman→Liberation Serif, Courier New→Liberation Mono, Georgia→Gelasio, Tahoma/Verdana/Segoe UI/Trebuchet MS→Open Sans (metric-compatible or look-alike open fonts; the file keeps the original name).
- Arabic fonts (Cairo, Amiri, Tajawal, Almarai, Noto Naskh/Kufi; Traditional/Simplified Arabic → Noto Naskh; Sakkal Majalla/Arabic Typesetting → Amiri) are bundled at build time from `@fontsource/*` by `scripts/arabic-fonts.py`. This step needs `npm install` and was only tested with mock files; a missing package prints a warning and that font falls back to the system font.
